[315. Count of Smaller Numbers After Self](https://leetcode.com/problems/count-of-smaller-numbers-after-self/description/)

## [!(ProblemDefinition)] Definition

Given an integer array nums, return an integer array counts where counts[i] is the number of smaller elements to the right of nums[i]

## Fenwick Tree Ds Solution

### [!(ProblemIntuition)] Intuition

- Coordinate Compression:
        - map each value to its 1-based rank among sorted distinct values;
        - example: `nums=[5,2,6,1,2]`, distinct sorted = `[1,2,5,6]` -> `ranks={1:1, 2:2, 5:3, 6:4}`.

- Sweep right → left:
        - for each `nums[i]`, query how many already-inserted ranks are smaller, then insert `ranks[nums[i]]`.

- Fenwick Tree (Binary Indexed Tree):
        - maintains prefix sums over a conceptual frequency array `freq`, where `freq[r]` = count of inserted elements with rank `r`.
        - $$
            - \text{tree}[i] = \sum_{t = i - (i \& -i) + 1}^{i} \text{freq}[t]; \text{ block length} = i \& -i.
        - $$

### [!(ProblemTimeComplexity)] Time Complexity

- O(n log n):
    - n = len(nums); each `query`/`update` is O(log K), K = number of distinct values.

### [!(ProblemCodeSnippet)] Code Snippet

```python meta="source=problems/315-count-of-smaller-numbers-after-self/fenwick-tree-ds.py"
class Solution:
    def countSmaller(self, nums: list[int]) -> list[int]:

        ranks = {v: i+1 for i, v in enumerate(sorted(set(nums)))}
        tree = [0] * (len(ranks) + 1)
        res = [0] * len(nums)

        def update(i):
            while i < len(tree):
                tree[i] += 1
                i += i & -i

        def query(i):
            s = 0
            while i > 0:
                s += tree[i]
                i -= i & -i
            return s

        for i in range(len(nums) - 1, -1, -1):
            r = ranks[nums[i]]
            res[i] = query(r - 1)
            update(r)

        return res
```

```python meta="source=problems/315-count-of-smaller-numbers-after-self/list-ds.py"
import bisect

class Solution:
    def countSmaller(self, nums: list[int]) -> list[int]:

        counts=[0]*(n:=len(nums))
        X=[]

        for i in range(n-1,-1,-1):
            x=nums[i]
            index=bisect.bisect_left(X,x)
            if index ==len(X):
                X.append(x)
            else:
                X.insert(index,x)
            counts[i]=index
        return counts
```
