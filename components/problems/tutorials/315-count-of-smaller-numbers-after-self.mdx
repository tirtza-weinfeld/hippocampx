[315. Count of Smaller Numbers After Self](https://leetcode.com/problems/count-of-smaller-numbers-after-self/description/)

## [!(ProblemDefinition)] Definition

Given an integer array nums, return an integer array counts where counts[i] is the number of smaller elements to the right of nums[i]

## Fenwick Tree Ds Solution

### [!(ProblemIntuition)] Intuition

- Traverse right → left:
    - Maintain a frequency structure of values already seen.
    - For each number:
        - `query(r - 1)` gives how many strictly smaller values exist
        - `update(r)` inserts the current value
    - Fenwick Tree idea:
        - `tree[i]` stores the sum of a specific range of frequencies.
        - The size of that range is determined by the lowest set bit of `i`.

- Deep dive:Bit trick:
        - `i & -i` isolates the lowest set bit of i.
        - Example:
            ```
            i = 12  -> 1100
            -i      -> 0100 (two’s complement)
            i & -i  -> 0100 (4)
            ```
        - That 4 means index 12 is responsible for a block of size 4.
        - Moving:
            - `i += i & -i`   → jump to next block that includes this range
            - `i -= i & -i`   → move to parent block in prefix sum

### [!(ProblemTimeComplexity)] Time Complexity

- O(n log n)

### [!(ProblemCodeSnippet)] Code Snippet

```python meta="source=problems/315-count-of-smaller-numbers-after-self/fenwick-tree-ds.py"
class Solution:
    def countSmaller(self, nums: list[int]) -> list[int]:

        ranks = {v: i+1 for i, v in enumerate(sorted(set(nums)))}
        tree = [0] * (len(ranks) + 1)
        res = [0] * len(nums)

        def update(i):
            while i < len(tree):
                tree[i] += 1
                i += i & -i

        def query(i):
            s = 0
            while i > 0:
                s += tree[i]
                i -= i & -i
            return s

        for i in range(len(nums) - 1, -1, -1):
            r = ranks[nums[i]]
            res[i] = query(r - 1)
            update(r)

        return res
```

```python meta="source=problems/315-count-of-smaller-numbers-after-self/list-ds.py"
import bisect

class Solution:
    def countSmaller(self, nums: list[int]) -> list[int]:

        counts=[0]*(n:=len(nums))
        X=[]

        for i in range(n-1,-1,-1):
            x=nums[i]
            index=bisect.bisect_left(X,x)
            if index ==len(X):
                X.append(x)
            else:
                X.insert(index,x)
            counts[i]=index
        return counts
```
