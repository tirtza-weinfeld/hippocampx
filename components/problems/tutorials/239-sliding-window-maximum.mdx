## [!(ProblemDefinition)] Definition

Given an integer array `nums` and window size `k`,
    slide a length-k window from left to right (one step at a time)
    and return an array where each element is the maximum value inside the window at that position.

## [!(ProblemCodeSnippet)] Code Snippet

```python meta="source=problems/239-sliding-window-maximum/solution.py"
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: list[int], k: int) -> list[int]:
        window_max: list[int] = []
        q = deque()

        for i, num in enumerate(nums):
            while q and q[0] <= i - k:
                q.popleft()

            while q and nums[q[-1]] <= num:
                q.pop()

            q.append(i)

            if i >= k - 1:
                window_max.append(nums[q[0]])

        return window_max
```
