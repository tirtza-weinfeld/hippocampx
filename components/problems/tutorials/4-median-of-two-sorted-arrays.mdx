## [!(ProblemDefinition)] Definition

Given two individually sorted arrays nums1 (size m) and nums2 (size n), compute the median of their combined multiset without merging them, in total time O(\log(m+n)).

<MedianOfTwoSortedArraysIllustration size="full" />

## [!(ProblemIntuition)] Intuition

- Binary search for a partition in the smaller array such that the combined
    - left half's elements are all less than or equal to the combined right half's elements.
    - The median is then derived from the boundary values of this partition.

## [!(ProblemTimeComplexity)] Time Complexity

- $O(log(min(m, n)))$
    - Binary search is performed on the shorter array.

## [!(ProblemCodeSnippet)] Code Snippet

```python meta="source=problems/4-median-of-two-sorted-arrays/solution.py"
class Solution:
    def findMedianSortedArrays(self, a: list[int], b: list[int]) -> float:
        if len(a) > len(b): a, b = b, a
        m, n, low, high = len(a), len(b), 0, len(a)

        while low <= high:
            i = (low + high) // 2
            j = (m + n + 1) // 2 - i

            al = a[i-1] if i > 0 else float('-inf')
            ar = a[i] if i < m else float('inf')
            bl = b[j-1] if j > 0 else float('-inf')
            br = b[j] if j < n else float('inf')

            if al <= br and bl <= ar:
                if (m + n) % 2: return float(max(al, bl))
                return (max(al, bl) + min(ar, br)) / 2.0

            if al > br: high = i - 1
            else: low = i + 1
```
