## [!(ProblemDefinition)] Definition

Given two strings `s` and `t` of lengths `m` and `n` respectively,     return the minimum window substring of `s` such that every character in `t` (including duplicates)     is included in the window. If no such window exists, return an empty string `""`,
    *[19!]solve it in linear time complexity O(m + n)*

## [!(ProblemCodeSnippet)] Code Snippet

```python meta="source=problems/76-minimum-window-substring/solution.py"
from collections import Counter

def min_window(s: str, t: str) -> str:
    deficit, missing = Counter(t), len(t)
    best, l = (0, len(s) + 1), 0

    for r, c in enumerate(s):
        missing -= deficit[c] > 0
        deficit[c] -= 1

        while not missing:
            if r - l + 1 < best[1] - best[0]:
                best = (l, r + 1)

            deficit[s[l]] += 1
            missing += deficit[s[l]] > 0
            l += 1

    return "" if best[1] > len(s) else s[best[0]:best[1]]
```
